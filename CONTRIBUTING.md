# Berkontribusi

Terima kasih sudah ingin memperbaiki skill ini.

1. Buka issue untuk kesalahan aturan atau usulan fitur.
2. Untuk perubahan copywriting, sertakan contoh sebelum/sesudah menggunakan data fiktif atau disamarkan.
3. Untuk klaim biaya seller, cantumkan tanggal, kategori, program, dan tautan resmi. Jangan menyebut angka simulasi sebagai tarif universal.
4. Jangan unggah invoice, rekening, nomor seri/IMEI utuh, alamat, atau chat pembeli dengan data pribadi.
5. Pull request sebaiknya fokus pada satu perbaikan dan mempertahankan bahasa Indonesia yang natural.
